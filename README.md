# Foo Alignerr Project

This is a Java project using Dropwizard framework.

## About

This project demonstrates a minimal Dropwizard application.

## Setup

Follow the instructions in `docs/0_SETUP_RULES.md`.

## Building

The project uses Maven. To build the project, run:

```bash
mvn clean package
```

## Running

You can run the application using the following command:

```bash
java -jar target/foo-alignerr-project.jar server config.yaml
```

If you don't have a `config.yaml`, you can use the example configuration.

## Documentation

For more documentation, see the `docs/` directory.
