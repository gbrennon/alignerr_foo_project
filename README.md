# User Registration CLI

This project is a Command Line Interface (CLI) that simulates the User registration workflow.

## Libraries Used

- **typer**: Used as the main library to build the CLI application.

## Features

- Accepts a `name` argument to personalize the greeting message.
- Prints a greeting message using `typer.echo`.

## Usage

To run the application, use the following command:

```bash
python main.py [name]
```

If no name is provided, the default value "World" will be used.
