This project was created to manage a collection of bands using object-oriented programming principles in Python. We started by defining a `Band` class using a dataclass to ensure all required attributes (`id`, `name`, `genres`) are present and correctly typed. The `id` attribute is a UUID generated by a static `create` method which also validates that the `genres` list contains at least one genre. 

To manage instances of `Band`, a `BandRepository` class was implemented. This repository utilizes a dictionary to simulate a database, storing bands by their UUID. It supports adding bands and retrieving them, providing a simple yet effective data management solution. 

Unit tests were written for both the `Band` and `BandRepository` classes to ensure that creation validations and repository operations work correctly. The project is managed using Poetry for dependency management, allowing easy installation of packages and running of tests using `pytest`. Documentation for each major step and component is maintained in the `docs/` directory. All source code, tests, and documentation are version-controlled using Git.
